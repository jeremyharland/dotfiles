# dotfiles (retired)

This repo's macOS config (nix-darwin, home-manager, nvim, tmux, ghostty,
ssh, superwhisper) has moved to
[jeremyharland/nix-config](https://github.com/jeremyharland/nix-config),
restructured as a bgub/nix-style flake with no GNU Stow dependency.
